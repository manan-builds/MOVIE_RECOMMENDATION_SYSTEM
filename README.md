MOVIE RECOMMENDATION SYSTEM

Project Overview
This project focuses on analyzing movie data to extract meaningful insights, predict user preferences, and recommend similar movies using machine learning techniques. It demonstrates the complete data science workflow—from data cleaning and visualization to building and evaluating machine learning models.


Objectives
•Explore and analyze a real-world movie dataset
•Identify trends in genres, ratings, and popularity
•Predict whether a user will like a movie
•Recommend similar movies based on learned patterns

Comparision between logistic regression and decision tree is shown.Visualization og each of them is present to understand the project better.
